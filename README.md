# 🌿 EcoTrack - Yapay Zeka Destekli Sürdürülebilir Yaşam Platformu

EcoTrack, bireylerin çevre bilincini artırmak, atık ayrıştırma alışkanlığı kazandırmak ve iklim krizine karşı farkındalık yaratmak amacıyla geliştirilmiş **oyunlaştırılmış bir e-ekonomi ve yapay zeka web platformudur**.

---

## 🚀 Öne Çıkan Özellikler

- 📸 **Canlı AI Atık Tanıma (TensorFlow.js & COCO-SSD):** Tarayıcı üzerinden kamerayı açarak plastik, kağıt ve elektronik atıkları gerçek zamanlı tespit eder ve doğru geri dönüşüm kutusuna yönlendirir.
- 🌲 **Sanal Orman & Oksijen Üretimi:** Dikilen ağaç türlerine göre günlük oksijen üretimi hesaplanır.
- 🚜 **Dinamik Eko-Tarım & Pazar Ekonomisi:** Ormanın ürettiği oksijen miktarı, pazardaki sebze satış fiyatlarına bonus çarpanı olarak yansır.
- 👣 **Karbon Ayak İzi Hesaplayıcı:** Ulaşım, beslenme ve enerji alışkanlıklarına göre yıllık emisyon raporu sunar.
- 🧠 **10 Soruluk İnteraktif İklim Quizi:** Bilgi düzeyini ölçer ve kullanıcıyı Eko-Para ile ödüllendirir.

---

## 🛠️ Teknoloji Yığını

- **Backend:** Python 3, Flask, Jinja2
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript (ES6+)
- **Yapay Zeka:** TensorFlow.js (`@tensorflow-models/coco-ssd`), WebRTC MediaDevices API
